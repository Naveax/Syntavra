# M6 Reconciliation Record

Each admitted roadmap candidate or P0 family must be reconciled before implementation with at least:

- canonical owner(s);
- classification: `EXISTS`, `HARDEN`, `UNIFY`, `NEW`, `CERTIFY`, `EXTERNAL`, or `DEFERRED`;
- dependency/invalidation edges;
- existing evidence and verifier coverage;
- minimal missing behavior, if any;
- acceptance/verifier contract;
- external evidence boundary where applicable.

Numeric capability order never overrides dependency and evidence order.
